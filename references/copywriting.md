# 文案：吸引力与热点借势（v2）

写给「第 1 步 写旁白稿」用。四段功能顺序不变（SKILL.md 硬约束第 8 条），但**句数区间放宽到 ①钩子 1 ②起因 3~8 ③冲突 5~20 ④升华 2~4，全篇硬上限 30 句**（v2.11.0）：文案为主，句子可以多，**单句仍按 16~22 字写**，多出来的句必须有独立画面信息。本文只回答一件事：**同一个故事，怎么写才让人不划走、还想吵起来**。

写完之后还要过一份 **`anti-ai-check.md`（去 AI 味三层体检）**：A 层由 `scripts/check_ai_patterns.py` 机械判定（有硬伤不许建篇），B 层是下面 15 条自检的细化判据，C 层是**反向规则**（通用去 AI 味清单里「不下判断/不要升华/允许跑题/第一人称」在本技能里不执行）。

分三层：**写法层**（每篇都能改的四个招）、**借势层**（热点靠排期不靠追）、**发布层**（一半的热点在片外）。

## 写法层：四个招，每篇都能改

### 招 ① 钩子从「说事件」升级为「戳身份」

前 3 秒观众只认一件事：**这事跟我有关**。所以钩子有两个轨道——

| 轨道 | 用法 | 适用 |
|---|---|---|
| **事件轨**（默认） | 直接抛结果或反常识，靠信息缺口抓人 | 典故本身够硬、受众泛 |
| **身份轨**（升级） | 把历史事件翻译成现代处境，让人认领自己的身份 | 事件本身不够炸，或要打进职场/社交圈层 |

身份轨对照表：

| 现有钩子（事件轨） | 升级版（身份轨） | 增强点 |
|---|---|---|
| 一天之内，十二道金牌召他回京 | 他打赢了所有仗，却输给十二道文件 | 「文件」戳中每个被流程搞垮的人 |
| 这顿饭，本该要了刘邦的命 | 史上最危险的饭局：赴宴的人知道自己会死，还是去了 | 「饭局」自带社交共鸣，节前发尤其炸 |
| 一把匕首，差一寸没刺中秦王 | 他离改写历史，只差一寸 | 数字反差推到极致 |

**轨道选择规则**：钩子仍 ≤15 字；身份轨只改开头一句，**正片语气不动**。网感只进钩子和标题，旁白保持电影质感，否则人设会散。

### 招 ② 中段每 3~4 句埋一个「没想到／但是」

转折词是完播率的命门——观众不是在听历史，是在等「然后呢」。

**硬规则**：每一段（尤其冲突段）至少一个反转点；**没有反转的铺垫，砍掉或并句**。
合格样板是「三连反转」结构：项伯反水 → 项庄舞剑 → 樊哙闯帐。每 3~4 句一次翻盘，句子之间必须有信息增量。
自检方法：逐句问「这句有没有推翻上一句的预期」；连续两句都答「没有」，就删掉或合并。

### 招 ③ 一个「蝴蝶效应细节」

在关键场景放大一个看似无关的小事，当命运转折点。抽象的判断没有宿命感，具体的动作才有。
- ❌「项羽心软，留他喝酒」→ ✅「范增举了三次玉玦，项羽低头喝了口酒」
- 细节要**可看见**：器物、次数、动作、时间点。越具体，宿命感越强。
- 每篇一个就够，多了变堆砌。

### 招 ④ 选题「三点法」：争议点、反转点、记忆点，占两点才做

| 点 | 含义 | 例（鸿门宴） |
|---|---|---|
| **争议点** | 观众能分成两派吵起来 | 项羽该不该放刘邦 |
| **反转点** | 有「没想到」的走向 | 杀机四伏却全场没动手 |
| **记忆点** | 一句能被复述的画面或标签 | 史上最危险的饭局 |

三点全占＝优先排；只占一点，换选题，别硬做。

## 借势层：热点不是追出来的，是排期排出来的

- **蹭档期**：影视/游戏热（三国类新赛季、历史剧开播）→ 提前排相关篇；节日映射（春节=饭局篇，清明=岳飞／意难平篇，开学季=科举篇）。**提前 1~2 周备片**，热度到了直接发。
- **蹭现代议题**：职场（十二道文件）、逆袭（亭长到皇帝）、社恐（樊哙 vs 唯唯诺诺的刘邦）——**只在标题和钩子里点到为止**。
- **意难平是历史赛道第一流量情绪**：标准曲线＝「十年之功 → 一天毁掉」。选篇优先找同款曲线，其次才看知名度。
- **排期表意识**：选题时先问「这篇适合哪个时间窗」，没有窗口的选题降级。

## 发布层：热点的一半在片外

- **标题默认＝篇名（v2.11.0）**：发布标题就用本篇主题名（＝成片名），需要张力时加**破折号副题**（`和珅跌倒：一笔烂账压了十五年`）。理由：篇名、封面、标题三套话术分裂，观众点进来发现不是那回事，完播率直接掉。副题里再套公式（悬念＋数字＋身份词），不用整句标题党。成片名仍用纯主题名（不加后缀）。
- **三组候选＝标题 + 核心思想 + 描述**：核心思想一句 **15~25 字**（这篇讲什么、立什么判断）；描述 **60~120 字**，前 30 字是钩子（抖音折叠前只露两行），后面接核心，末句留半句给评论区。三组要有区分：一组抛结果、一组抛代价、一组留悬念。
- **评论区钩子**：金句定帧卡之后留一个**可争论的问题**——「换成你，放不放刘邦？」
  写进 `script.json` 的 `discussion` 字段（建篇时 `--discussion "..."`），出片后随 `项目说明_v12.json` 输出，发布时直接抄成评论首条。**评论互撕＝算法推流，最便宜的热点。**
- **封面 kicker**：`make_cover.py --kicker` 从卷名换一句反差短语，如「一念之仁，输掉天下」；主标 ≤8 字，副题用金句（`needle`）。

## 口语化改写对照表

| 书面 | 口语 |
|---|---|
| 于是、因而、遂 | 结果、就这么 |
| 其、之、该 | 他的、这个 |
| 进行、实施、予以 | 直接动词：做、砍、烧、埋 |
| 众多、大量 | 给数字：三千、十七个 |
| 十分悲痛 | 给动作：他没说话，把碗放下了 |

单句以 **16~22 字**为宜（横版硬上限 22、竖版 18）。**短句不等于好，信息密度才是目标**——先写到贴上限，超了再删修饰或拆句，别一上来就写成 8 字碎句。念一遍：**念着别扭的地方，就是观众走神的地方**。

## 字数双向调节（写稿时贴着上限写）

一两句话要把一件事说清，靠的不是短，而是密度。字数是**双向**的：不够要补，超了要删。

| 情况 | 怎么调 |
|---|---|
| 句子偏短（信息不足） | 并句（两句合成一句），或**补一个看得见的动作/数字**（「他慌」→「他把茶碗扣在桌上，手抖了一下」），把句子填到 16~22 字 |
| 句子超过上限 | 先删修饰词（形容词、程度副词、"其实/真的/突然"），还是超就**拆成两句**（在逗号或转折处断） |
| 句子里从句超过两个 | 直接拆，别在长句里塞因果 |
| 但**钩子** | 照旧 **≤15 字**，不参与调节——短促才抓人 |
| 但**末句金句** | 照旧 **≤20 字**，不参与调节——它要当片尾字卡 |

口诀：**中间的句子贴着上限写满，两头的句子（钩子、金句）往短里写。** 一篇 15 句里有 8~10 句落在 16~22 字，观众才觉得"讲了东西"；全是 8~10 字碎句，念完什么也没记住。句数放宽到 30 句也一样——**30 句不是 30 个碎句，是 30 句各带一条信息**。

## 沉重的历史感（怎么写才沉，不靠形容词）

沉重不是「很悲壮」，是**算得清的代价**。八条硬规则，写完逐条过：

1. **用数字和器物代替形容词**：「八千人就回来三百」「杀马三千匹，吃了二十天」「一船瓷器换回八十匹瘦马」。形容词是作者的感受，数字是事情的重量。
2. **写因果链，不写情绪**：写「令人唏嘘」读者不会唏嘘，写「他把奏折压在砚台下，再没拿出来」读者才会。情绪交给观众算，别替他算。
3. **把代价落在可数的人或物上**：死的是「三千人」不是「无数将士」；丢的是「四座城」不是「大片国土」。不可数＝不可感。
4. **用当时的词，不用概括的词**：御史、给事中、廷杖、籍没、流三千里、夺俸半年。概括词等于隔了一层玻璃；原词自带时代的凉气。
5. **沉重感来自无力感**：主角不是打不过，是**在结构里没有选择**——调不动兵、发不出饷、等不来批复。让观众看见那张网，别只看见他不甘心。
6. **删掉心理活动**：不写「他感到/他知道/他明白」，换成一个动作、一句对话、一个物件。心里的事一写就轻，一演出来就重。
7. **结尾不下判断，只留一个具体画面**：空船坞、没寄出的信、没人接的印、未批的奏折、凉了的茶。判断留给评论区，画面留给他自己。
8. **节奏压住**：短句收尾、少从句、每 3~4 句一个反转、单句仍 16~22 字（不参与下调，也不许拉成 30 字的复句）。沉不是慢，是每一句都往下坠一点。

**改写示范**

> 前：那一年冬天，他在风雪中坚守，历史的尘埃落在肩上，悲壮而苍凉。
>
> 后：城里的米吃完了。他下令杀马，三千匹，吃了二十天。援兵还在三百里外。

差别只有三处：数字（三千匹、二十天、三百里）、动词（吃完、下令、杀、吃）、删掉了所有替他抒情的词。**同一件事，写实了才重。**

## 合规底线

- 不编造数据、引文、野史当正史；争议结论标注为「一种解读」。
- 不消费苦难，不做地域/性别/民族对立，不用「最／唯一／彻底」等绝对化断言。
- 涉及当代人物与事件不做影射式评价；敏感题材、政策议题不碰，拿不准就换选题。

## 交稿前自检（15 条，逐条打钩）

**写法层**
- [ ] 钩子 ≤15 字，是结果或反常识；**已判断走事件轨还是身份轨**，身份轨只改首句
- [ ] 起因只有一条因果链，专名能省则省
- [ ] 每段至少一个反转点，**每 3~4 句有一次「没想到／但是」**；无反转的铺垫已删或并句
- [ ] 冲突段写清「付出了什么」：至少一个具体数字或动作，无形容词堆叠
- [ ] 全篇至少一个蝴蝶效应细节（可看见的器物/次数/动作）
- [ ] 选题过三点法：争议／反转／记忆**至少占两点**
- [ ] 末句 ≤20 字，能复述、有对立，不是口号
- [ ] 全篇句数 ≤30，四段落在 ①1 ②3~8 ③5~20 ④2~4；钩子只有 1 句，不补第二句
- [ ] 沉重感落在数字与器物上：至少三处可数代价（人数／物数／天数／距离／银钱），替他抒情的形容词已删；结尾只留一个具体画面
- [ ] 单句落在 16~22 字（横版硬上限 22 字、竖版 18 字，脚本会给提示）；不写 8 字碎句，也不留拗口长句；钩子 ≤15 字、末句 ≤20 字不参与这条
- [ ] 同一人物称呼全片统一：首句可全名一次，之后固定短名；尊称只在引语里、最多两次
- [ ] 三项排比只为节奏留、不为凑数留；凑数的那项已拆
- [ ] 一句最多一个 `——`；情感写成动作，不写成标签（「他站在原地，没有回头」而不是「令人悲伤」）

**借势与发布层**
- [ ] 已确认这篇的时间窗（档期/节日/议题），有无窗口写在选题备注里
- [ ] 三组发布候选已拟好并写进 `script.json.titles`：标题默认＝本篇主题名（张力才加破折号副题），核心思想 15~25 字，描述 60~120 字、前 30 字是钩子，与正片一致不标题党
- [ ] `discussion` 已写入（一句能吵起来的话，不是求赞）
- [ ] 封面 kicker 已定（反差短语 ≤8 字）

## 改写示范（同一题材，前后对照）

**改写前**
```
今天我们讲一个关于忠诚的故事。
他出生在北宋末年，是著名的抗金将领。
他带领军队多次击败敌人，立下赫赫战功。
但是朝廷内部有奸臣当道，对他十分忌惮。
最终他被召回，含冤而死。
他的精神值得我们永远铭记。
```
问题：钩子交代形式、起因是年表、冲突无代价、无反转、结尾喊口号。

**改写后**（结构 1,2,4,2，身份轨钩子）
```
他赢了所有仗，却输给十二道文件。          ← ① 身份轨钩子
那年他三十九岁，兵在他手里，粮在他手里。  ← ② 处境
所有人都知道，回去就是死。              ← ② 反转
他还是回了，一个人，一匹马。            ← ③ 代价 1
牢里没有纸，他把背上的四个字给狱卒看。    ← ③ 蝴蝶效应细节
罪名是"莫须有"，三个字，没人敢改。       ← ③ 不可逆
他死后二十年，才有人敢给他修墓。        ← ④ 时间拉开
他守住了国，没守住自己。                ← ④ 金句兼片尾卡
```
