# shots.json 字段与素材引用

`shots.json` 是「每篇专属」的唯一配置。路径字段以该文件所在目录（`episodes/<id>/`）为基准。渲染引擎 `make_v12.py --episode <shots.json>` 读取它，换篇不改引擎。

**没有固定数量**：镜头数 = 旁白句数；`images` 任意张、`motions` 任意段、动态镜任意个。

## 顶层字段

| 字段 | 含义 |
|---|---|
| `id` / `title` / `volume` | 篇 id、标题、分类/卷名；由 `meta.json` 提供，此处仅作人读冗余；片头不显示编号 |
| `format` | **可选**，画幅：`"16:9"`（默认，横版 1920x1080）/ `"9:16"`（竖版 1080x1920）。`start_story.py --format` 写入；命令行 `--format` 优先。竖版下片头自动不出现说书人（`head.mode` 强制 `title`，口播保留），字幕按竖屏安全区重排（见下节） |
| `engine` | 固定 `v12` |
| `status` | 当前状态；含「占位」/「缺本篇画面」时引擎拒绝出正式片，只有「本篇素材已就位」且图片不指向内置占位目录才可出片 |
| `paths_relative_to` | 固定「本文件所在目录」 |
| `images` | 本篇场景图路径列表，**任意张数**（可为 0）；不用的图直接删掉，不要留 null |
| `motions` | 本篇动态素材路径列表，**任意段数**（可为 `[]`）；动态镜默认一镜一素材，段数应 ≥ 动态镜数 |
| `motion` | 旧版单段字段，仍兼容；与 `motions` 并存时以 `motions` 为准 |
| `accents` | 重音句序号（0 起算），如 `[2, 5, 12]`；序号须小于镜头数 |
| `shots` | 镜头对象列表，**长度至少等于旁白句数**（多出的忽略） |
| `head_text` | 片头说书人台词，模板「今天讲一个{title}的故事。」 |
| `host` | 片头说书人：`ancient`（默认，古装）/ `modern`（现代休闲学者）。按故事题材判断（古代/神话/历史→ancient，近现代/当代/现实→modern）。省略等于 ancient，旧篇行为不变；两套素材随技能自带、零积分复用 |
| `head_image` | 本篇片头底图（相对本篇目录或绝对路径），兼作最代表性一镜。**优先用片头专属图 `片头图/head_16x9.jpg`**（由 `head_cover.py` 从本篇那张 16:9 横图切出，1920x1080，与正片任何一镜都不重复）；没有专属图时才回退到场景图——`fill_shots.py` 默认取中间那张、`--head-image` 可换。老篇没写的沿用 runtime 内置底图 |
| `head_video` | **可选**（按开工确认第 2 项决定，仅横版有此项），本篇专属口型视频（相对本篇目录），VideoGen 用本篇音轨驱动生成，音视频同源真同步；不写则沿用当前 `host` 的内置口型视频（`ancient`→`talk_test.mp4`，`modern`→`talk_modern.mp4`，旧式换音轨，唇形近似但零积分，**可用于正式片**，140/186/002 即如此）。生成法见 workflow.md「片头音轨规则」 |
| `head` | **可选**，片头模式：`{"mode": "host", "voice": true, "len": null}`。`host`=说书人 5 秒口播（默认，省略即旧行为逐字不变）；`title`=片头不出现人像，只留标题卡+底图，时长不写死 5 秒。`title` 下 `voice` 默认 `true`=保留片头口播与字幕，片头长度按语音实测自适应（语音终点 + 0.95s，含 0.8s 交叉溶解）；`voice:false` 则片头纯静音无字幕，长度按篇名估（0.9+0.21×字数，夹 2.0~3.6 秒）。`len` 可显式指定并覆盖自适应。建篇 `--head-mode title [--no-head-voice] [--head-len 3.9]` |
| `ending` | **可选**，结尾针片尾定帧卡配置；不写则引擎不加片尾卡，行为与 v12 原版一致 |
| `bgm` | **可选**，背景音乐配置；不写或 `enabled:false` 则无 BGM（默认）。字段：`enabled` 布尔、`theme`（神话/史诗/哲思）、`root` 基频（A3=220）、`seed` 旋律随机种子、`volume` 基础音量（默认 0.18）、`file` 真实音频路径（相对本篇，给了就跳过合成）。渲染时也可用 `--bgm` / `--no-bgm` 临时覆盖开关 |
| `todo` | 待办；占位素材未替换完之前不得清空 |

## script.json（四段式剧本）

与 `lines.json` 同目录。`lines.json` 保持**纯字符串数组**（TTS / SRT 链路不读 script.json），四段归属单独记在这里。

| 字段 | 含义 |
|---|---|
| `template` | 固定四段顺序 `① 3秒钩子 → ② 背景起因 → ③ 核心冲突 → ④ 结局升华`，顺序不可换 |
| `structure` | 四段各自句数，如 `[1, 3, 7, 2]`；总和须等于旁白句数，**每段几句自由** |
| `segments` | 数组，每项 `{key, label, lines, max_chars}`；`lines` 是 0 起算的 `lines.json` 下标，四段合起来不重不漏覆盖全部句子 |
| `needle` | 结尾针金句，默认取 `lines.json` 最后一句 |
| `hook_max_chars` / `needle_max_chars` | 15 / 20；建篇时超字只警告不拦截 |
| `auto` | `true` 表示四段区间按句数比例自动推断，需人工复核；显式 `--structure` 时为 `false` |
| `discussion` | **可选**，评论区钩子问题（一句能吵起来的话，如「换成你，放不放刘邦？」）。建篇时 `--discussion "..."` 写入；不写则无该键，产物与旧版一致。出片后由引擎读入并写进 `_render/项目说明_v12.json`，发布时直接抄成评论首条 |

`start_story.py` 会据此把每个镜头的 `beat` 写成对应的段落名（① 3秒钩子 / ② 背景起因 / …），可再按情节细化。

## ending（结尾针片尾定帧卡）

| 字段 | 含义 |
|---|---|
| `hold` | 金句字卡停留秒数，参考 `2.5`；实际窗口由 `vo.wav` 尾部留白决定 |
| `gap` | 末句旁白结束到卡片淡入的间隔秒，默认 `0.45` |
| `fade_out` | 卡片结束到片尾的留白秒，默认 `0.25` |
| `needle` | 可选，字卡金句；不填自动取 `lines.json` 末句 |
| `credit` | 可选，落款；不填自动用「卷名 · 篇名」 |

- 结尾针是「A 文案针 + B 定帧卡」合体：**同一句**先念出来，再钉在卡上，不额外加旁白。
- 卡窗口 = `vo.wav` 尾部留白 − `gap` − `fade_out`；`new_episode.py` 的 `TAIL` 已从 1.5 扩到 3.6 秒，窗口约 2.9 秒。旧 `vo.wav` 不自动变化，重跑建篇才刷新；窗口不足 1.2 秒时引擎会警告并跳过片尾卡。
- 引擎只在 ASS 里加片尾事件（半透明压暗矩形 + 居中金句 + 落款 + 淡入淡出），**不动滤镜图**；`--tail 8` 可单渲这段验收。

## shots[] 字段

| 字段 | 含义 |
|---|---|
| `n` | 镜头序号，0 起算，与数组下标一致 |
| `beat` | 叙事作用：交代背景 / 建立人物 / 制造冲突 / 完成反转 / 收束——按情节标注，不按句子机械配图 |
| `src` | 素材引用，见下节 |
| `lens` | `[起始缩放 z0, 推进量 dz, x静态偏移, y偏移, 保留字段, 是否镜像]`；x 固定不左右摆动，只保留静态取景偏移 |
| `move` | **可选**运镜。**不写就按 `note` 标签自动选**（v2.7.0 起默认 auto）并套节奏约束；想钉死就写 `{"type": "zoom"\|"pan_x"\|"pan_y"\|"hold", "amount": …, "dir": …}`；想退回旧版纵向浮动写 `{"auto": false}` 或 `{"type": "legacy"}`。`zoom` amount 0.01~0.08（绝对 zoom 增量）；`pan_x` amount 0.05~0.5（横向余量比例，技能层建议 ≤0.3 且只给远景/空镜）；`pan_y` 用 `MOTION_SCALE` 缩放幅度；`hold` 完全不动。**动态镜忽略该字段** |
| `phase` | 动态镜在素材中的起始相位（秒），仅动态镜需要 |
| `motion` | `true` 表示这是真动态镜 |
| `crop16x9` | 动态镜专用：3:2 素材裁 16:9 用 `true`；16:9 素材设 `false`（缺省按 `true`） |
| `dim` | `true` 表示压暗处理（配合 `eq` 提对比） |
| `note` | 画面内容备注，供生成图片时写提示词；提示词固定前置风格句：写实电影剧照，电影级自然光，浅景深，写实历史剧质感，无文字，无字幕，避免人物正脸大特写；**有人物的篇再前置一句本篇 `cast` 人物锚定句**；`note` 只写本镜独有的情节与景别 |

## cast（人物锚定句，有人物的篇建议写）

| 字段 | 含义 |
|---|---|
| `cast` | 可选，数组。每项 `{name, anchor}`，`anchor` 是全篇固定的造型描述，如 `{"name":"郑和","anchor":"同一人物：深青官袍、黑色幞头、革带、身形清瘦、四十上下"}`。写进该镜提示词，锁造型不锁脸 |
| 怎么填 | 建篇时 `start_story.py --cast "郑和=同一人物：深青官袍…"` 直接写入（可给多个），或事后手改 `shots.json`；不给则无该键，行为与旧篇一致 |
| 用法 | 每镜提示词 = 风格句 + 该镜用到的人物的 `anchor` + `note` 情节；跨年龄段/换装时按段落各给一套 `cast`（如「少年：粗布短褐」「晚年：石青蟒袍」） |

出镜节奏按 `SKILL.md` 硬约束 11e：主人翁出镜 50%~70%、远景→背影→近物轮换、每 3~4 镜一次可辨正脸、一镜两图两格至少一格有人；未出镜的镜用行动痕迹承载因果。

## src 素材引用写法

| 写法 | 含义 |
|---|---|
| `img:i` | **推荐**，引用 `images[i]`（第 i 张图），一镜一图 |
| `img2:i,j` | **一镜两图**，前半镜用 `images[i]`、后半镜用 `images[j]`，中间 0.3s 溶解；镜头数仍=句数，字幕/切镜点不变，两图各自走完整方向性平移 |
| `motion:j` | **推荐**，引用 `motions[j]`（第 j 段动态素材）；配 `motion: true` + `phase` |
| `[N:v]` | 旧式，引用输入槽 N 的图；旧镜头表仍兼容 |
| `[mv_a]` / `[mv_b]` | 旧式，引用第 0 段动态素材；引擎按出现顺序自动分配 split 路 |

- **动态镜默认一镜一素材**：一个 `motions[j]` 只服务一个镜。动态镜多于素材段时 `fill_shots.py --dynamic-at` 会直接报错，不静默复用。两种受控例外才加 `--reuse-motion`：① **同一动作拆相邻两段**（镜号相邻、phase 首尾相接）；② **环境连续体延展**（烟/火/雨/人流），且两镜景别不同、镜像/压暗/裁切至少再变一项。复用时光看画面就能看出是“同一段视频又放了一遍”，比静态图重复显眼得多；素材不够时宁可把多出的镜改回静态图。
- 复用模式下 `phase` **顺序相接**（后一镜从前一镜结束点起算，按 `caption.srt` 的句长累加），不再 1.5 秒等距乱铺；`phase` 逼近/超过素材时长会打印警告（等于从头重放）。分配结果逐镜打印「镜 → 第几段 / phase / 是否复用」，可直接核对。

- **一镜两图**（`img2:i,j`）：开工确认第 5 项选「每镜 2 张」时用。一个镜头内前后各半、短溶解切换，比一镜一图画面更丰富；`images` 张数须 ≥ 2×镜头数，且**下标成对**（镜 k 用 `img2:2k,2k+1`）。宫格出图时一张两宫格的两格正好是同一镜的前后半段（一张覆盖 1 镜、`images` 共 2×镜数 张），一张四格覆盖 2 镜；切出的 `pNN` 是全局序号，填图加 `--pairs` 由 `fill_shots.py` 自动配对（跳过动态镜），不加则顺序填 `img:i` 会串镜。不支持与动态镜（`motion:true`）同用；只写 `img:i` 的旧篇逐字不变。
- 同一段动态素材被多个镜引用时，引擎会自动 `split`（`resolve_srcs()`），各镜按自己的 `phase` 去 `trim`——**这是引擎能力，不是推荐做法**；技能层默认一镜一素材，只有 `--reuse-motion` 放行的两种例外才这么写。
- 图片输入由引擎自动加 `-loop 1 -framerate 25 -i`，不要在 `src` 里写文件路径。
- `fill_shots.py` 换图后会自动把越界的 `img:i` 重映射为 `i % 新图片数`。

## 输入槽如何计算（不用手工算）

引擎按实际数量排输入槽：

```
0 片头底 / 1 第 0 段动态素材（无动态时用底图占位）/ 2 片头 mask / 3 音频
4 .. 4+N-1         N 张图片
4+N ..             第 1 段起的额外动态素材
之后 6 个固定槽    fog_w / talk / fog_c / particles / shade / spark
固定槽起点 = 4 + N + max(0, M-1)
```

例如 N=11、M=1 时固定槽起点是 15；换成 N=4、M=0 时起点自动变成 8，不用改引擎。

## 真正的约束（只有这几条）

1. `shots[]` 的长度 ≥ 旁白句数，且每个镜头都有合法的 `src` 与 `lens`。
2. `img:i` 的 `i` < `len(images)`；`motion:j` 的 `j` < `len(motions)`。
3. 动态镜若引用 3:2 素材需 `crop16x9: true`，否则会横向拉伸。
4. 静态图仍须带 `-loop 1 -framerate 25`（引擎已处理）。
5. **系列复用层固定**：25fps、片头时长规则、4.2 秒交叉溶解、下方居中字幕、转场与响度链路——这些不是每集专属参数，别在 shots.json 里改。画幅只有两档（16:9 / 9:16），写在 `format`，不要自定义其他比例。

- `z0` 1.00~1.45 拉开静态景别差异；`dz`、`per` 为旧字段，保留兼容但已停用（不再推近、不再脉冲、不再摆动）。画面只做平滑上下浮动，各镜方向按奇偶交替。

- 镜头数不同时，`start_story.py` 会循环复用这张模板，再按需改。

## 新篇镜头表填写顺序

1. 跑 `start_story.py` 得到与旁白句数一致的镜头表（src / lens 已就位）；给了 `--images-dir` / `--images-paths` 时素材已是本篇画面，否则 `images` 为空并标记缺图。
2. 按情节给每镜写 `beat`，并给本篇写 `cast` 人物锚定句（有主角时），核对主人翁出镜是否落在 50%~70%、景别是否轮换。
3. 生成任意张数本篇场景图，写 `note` 作为提示词依据。
4. 用 `fill_shots.py` 替换 `images` / `motions`，必要时用 `--dynamic-at` 指定动态镜。
5. 渲 `--test 45`，抽帧确认各镜画面确实各不相同，且**同一个人前后造型一致**。

## 画幅（format）：16:9 / 9:16

两档画幅由引擎的 `FORMAT_SPECS` 统一定义，`format` 只是选择开关；**换画幅不用改镜头表**。

| 项 | 16:9（默认） | 9:16 |
|---|---|---|
| 成片尺寸 | 1920x1080 | 1080x1920 |
| 说书人 | 可选（`head.mode=host`） | **不出现**，`head.mode` 自动强制 `title`（口播保留） |
| 正文字号 / 左右边距 / 底部边距 | 54 / 220 / 115 | 48 / 54 / 300 |
| 篇名字号 / 上边距 | 66 / 128 | 56 / 300 |
| 卷名字号 / 上边距 | 34 / 72 | 28 / 200 |
| 片尾金句 / 落款字号 | 62 / 28 | 52 / 26 |
| 片尾卡位置 | 金句 y=500、落款 y=650 | 按画幅同比（约 y=889 / 1156） |

- 竖版字幕底部留 300px（约 15.6%）安全区，避开抖音/快手底部的账号名与操作栏、以及小红书底部文案区；左右各留 54px 避开右侧点赞栏。
- 竖版片头是**标题卡压在片头图上**，不再给说书人让位，所以片头图的人物可以更居中（不再要求「人物偏左、右侧留白」）。
- **动态素材**：竖版没有 16:9 可裁，`crop16x9:true` 的素材会改走「等比铺满 + 居中裁两侧」，横向素材会损失左右两侧构图——竖版篇建议不排动态镜，或改用竖拍素材并设 `crop16x9:false`。
- **分镜缓存**：缓存 key 含画幅（`wh`），同篇切画幅会重渲镜头，别指望复用横版中间片。

## 可选块：render（本篇渲染档）

```json
"render": {"cache": true, "encoder": "libx264", "ss": 3}
```

- `cache`：是否启用分镜缓存（默认 `false`）。开启后每镜先渲成 `缓存/镜头/NN_<hash>.mp4`，命中即复用。
- `encoder`：`libx264`（默认）/ `qsv`（Intel 硬件编码）/ `auto`（有 QSV 就用）。
- `ss`：超采样倍数 1~6，默认 3；1 会有阶梯卡顿。
- 命令行 `--cache/--no-cache`、`--encoder`、`--ss` 优先于本块；`start_story.py --profile fast|quality` 会自动写入。
