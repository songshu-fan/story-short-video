# 旁白稿去 AI 味体检（第 1 步写稿时执行）

写四段式旁白稿时，除了 `copywriting.md` 的 15 条自检，再过一遍这份体检。目标是**清掉机器腔，不伤爆款气质**。

去 AI 味的通用清单追求「中性、克制、不表态」，而本技能要「钩子、反转、意难平」——直接套会把片子洗成白开水。所以裁成三层：**A 层直接杀、B 层判断着改、C 层反着来**。

**执行顺序**：按 `copywriting.md` 写出四段 → 跑 A 层脚本（`check_ai_patterns.py`）→ 人工过 B 层 → 按 C 层确认没被"通用去 AI 味"洗软 → 建篇。

---

## A 层 · 直接杀（见到就改，无例外）

这些在旁白里只有坏处：念出来假、字幕里丑、占字数还不推进情节。其中前 5 类是**功能性硬伤**——emoji 缺字形会在字幕里出方块，`**` 会被 TTS 念出来，弯引号与直角引号混用会让字幕字形跳。

| 病 | 典型词 / 符号 | 改成 |
|---|---|---|
| 空洞升华 | 标志着 / 彰显着 / 见证了 / 在历史长河中 / 谱写了新篇章 | 删掉，或换成具体代价 |
| 模糊归因 | 专家认为 / 研究表明 / 有资料显示 / 众所周知 | 说清是谁；史实不确定就写「相传」或「据《史记》」（见下方口径） |
| 填充废话 | 值得注意的是 / 需要指出的是 / 在这个时候 / 总的来说 | 直接删，句子照样成立 |
| 万能积极结尾 | 未来可期 / 令人深思 / 值得我们学习 / 谱写了壮丽诗篇 | 换成结尾针的具体金句 |
| 客服腔 | 希望对你有帮助 / 当然可以 / 让我们来看看 / 接下来介绍 | 删 |
| 过度对冲 | 可能或许大概 / 在一定程度上 / 也许可以说 | 留一个确定判断 |
| 弯引号 `“ ” ‘ ’` | — | **硬伤，必须换成 `「」` 或去掉**。`「」` 本身合规、可放心使用；**常见误判：把 `「」` 当成弯引号** |
| emoji / 装饰符 | 🚀 💡 ✅ → ⭐ | 全删，正片字幕不该出现 |
| 机械加粗 / `**` | — | 删，`lines.json` 是纯字符串 |
| 半角 `-` 当长破折号 | 他-不是输给刘邦-是输给… | 改逗号或断句，给 TTS 换气点 |

**「相传」的段位口径**（原清单里两处表述会打架，以此为准）：

- **① 钩子段禁**「相传 / 很久以前 / 据说」——钩子要具体、要结果，模糊时间词等于放弃前三秒；
- **② 起因段可用**，但只用于**史实不确定处**，且必须写明来源层级（「相传」「据《史记》」），不能用来替自己模糊归因；
- **③④ 段**不再出现归因词，只写动作与代价。

## B 层 · 改造后用（判断着来，不一刀切）

这 6 条是 `copywriting.md` 15 条自检的**细化判据**，不另起第二套标准。写稿时可以对照，但最终以 15 条自检打钩为准。

| 病 | 为什么要判断 | 怎么处理 |
|---|---|---|
| 三项排比 | 凑数的三项要拆，但钩子和金句就靠三项打节奏 | 判据：推进信息→拆；制造节奏→留 |
| 同义词循环 | 称呼换来换去，字幕像机器生成 | 见下方「称呼统一」细则 |
| 华丽替代朴素 | 「作为……的见证」「拥有……的空间」绕弯 | 改回「是」「有」，省字数给 TTS |
| 假范围 | 「从低谷到巅峰，从迷茫到坚定」两边不在一把尺上 | 换成两个具体事实 |
| 情感标签化 | 「这是令人悲伤的一天」 | 换具体动作：「他站在原地，没有回头」 |
| 破折号堆砌 | 一句三个 `——` 是典型 AI 兴奋症 | 最多留一个，其余改逗号 |

**称呼统一细则（不按"同义词循环"一刀切）**：

1. 同一个人全片固定一个短名：项羽从头到尾叫「项羽」，不要「项王 / 西楚霸王 / 他」混着换主语；
2. **首句可用一次全名或带身份的全称**（如「钮祜禄·和珅」），之后固定短名（「和珅」），这不算同义词循环；
3. 臣子/下属口中的尊称（「相国」「中堂」）只在**引语或明确视角**里出现，且全片最多两次；
4. 代词「他」只在与上一句同一主语时用；换人必写名字，否则观众要回头找主语。

## C 层 · 反着来（通用去 AI 味规则在本技能里失效）

这几条别照搬，照搬会杀死爆款。**只记住"不要做什么"，不要在本技能里执行它们。**

| 通用规则 | 为什么不能套 | 本技能怎么做 |
|---|---|---|
| 「用第一人称我，才有灵魂」 | 说书人第三人称，一个「我」就跳出人设 | 保持说书人口吻，锋利靠判断不靠「我」 |
| 「不下判断、承认复杂、混合情绪」 | 爆款要争议点、要意难平 | 升华段明确站队，把判断钉在金句上 |
| 「不要升华、不要夸大意义」 | ④ 升华是四段式硬结构，末句是结尾针字卡 | 只清套话，不清价值落点 |
| 「允许跑题、留没说完的念头」 | 一句一镜，跑题就多一镜废画面 | 一句一信息，没反转的铺垫并句或砍掉 |

（「现代词只进钩子与发布文案」已在 `copywriting.md` 规定，此处不再重复。）

## 与四段式的对应关系

| 段 | 体检重点 |
|---|---|
| ① 3 秒钩子（1 句） | A 层禁「相传/很久以前」；用具体反差开场，禁空洞意义词；首句 ≤15 字，第二句才补处境 |
| ② 背景起因（3~8 句） | A 层杀模糊归因；史实标明传说/解读；只铺让冲突成立的信息 |
| ③ 核心冲突（5~20 句） | B 层查称呼统一、三项排比留节奏拆凑数；必须有「他付出了什么」；**全篇 ≤30 句** |
| ④ 结局升华（2~4 句） | C 层保判断锋利；A 层杀万能积极结尾；末句 ≤20 字且能当字卡 |

## 改稿示例（含四段完整版）

**原文（AI 味重）：**

> 鸿门宴标志着楚汉相争进入了一个新的阶段，彰显着历史发展的必然趋势。据专家分析，项羽的性格因素在其中发挥了至关重要的作用，这不禁令人深思。

问题：两句全靠套话撑着，没有一个可拍的动作，冲突段一句都没有。

**只跑 A 层（干净但塌了）：**

> 鸿门宴是楚汉相争的转折点。

干净了，但钩子没反差、冲突没细节、升华没判断——四段式塌成一句概述。

**三层体检后（可用于本技能）：**

> ① 那顿饭，本该要了刘邦的命。
> ② 项羽请客，刀斧手就埋在帐后。范增举起玉玦，连举三次。
> ③ 项羽低头，喝了口酒，没动。项庄起身舞剑，剑锋一直贴着刘邦的席位。张良看出不对，起身去找樊哙。
> ④ 他不是输给刘邦，是输给自己的体面。

改动轨迹：A 层杀掉「标志着/彰显着/据专家分析/令人深思」；B 层把「性格因素」拆成举玉玦、低头喝酒、剑锋贴席三个动作（三项同段但不凑数，各自推进信息）；C 层保住钩子的反差与末句的锋利判断，没套「不下判断」那条。

## 机械化体检：`check_ai_patterns.py`

A 层能机械判定的部分（emoji、弯引号、加粗/markdown、套话关键词、半角破折号、半角标点、单句字数）跑脚本扫：

```bash
python $SK/scripts/check_ai_patterns.py --lines <root>/episodes/<id>/lines.json
python $SK/scripts/check_ai_patterns.py --lines <root>/episodes/<id>/lines.json --format 9:16
python $SK/scripts/check_ai_patterns.py --lines <root>/episodes/<id>/lines.json --fix-quotes
```

| 参数 | 作用 |
|---|---|
| `--format 16:9 / 9:16` | 单句字数提示上限：横版 22 字 / 竖版 18 字（竖版折行就是 18 字/行） |
| `--fix-quotes` | 把弯引号 `“ ” ‘ ’` 就地换成 `「」` 并写回；其余硬伤照报不修 |
| `--json` | JSON 报告，供外部脚本消费 |
| `--quiet` | 只输出结论行 |

- 输出逐句命中报告：`[硬伤]` 一条即不可建篇，`[提示]` 人工判断；
- **退出码 0 = 干净，1 = 有硬伤**；
- **建篇会硬拦**：`start_story.py` 在写任何文件前先跑同一套规则，有硬伤直接退出；确实要强行建篇加 `--skip-ai-check`（不推荐，硬伤会进 TTS 与字幕）；
- B 层和 C 层脚本不碰——它们要理解剧情，机器判不了；
- 纯标准库、离线、零积分；不带 `--fix-quotes` 时不写任何文件。
